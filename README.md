## 🧸 Game Overview

**Alphabet Quest Kids** makes early spelling and alphabet mastery a playful, tactile adventure! 

Letters are placed on colorful 3D blocks in the center of the screen with missing slots waiting to be filled. Below, on a wooden toy tray, a deck of letter cards is ready for little hands to pick and place. With two game modes, uppercase/lowercase toggles, and gentle 3-attempt assistance, children build confidence and spelling skills without frustration.

---

## ✨ Features & Learning Mechanics

- **🧩 3 Quiz Tiers**:
  - **4-Letter Tier**: 1 missing letter | 4-letter bottom deck (1 correct + 3 distractors).
  - **6-Letter Tier**: 2 missing letters | 6-letter bottom deck (2 correct + 4 distractors).
  - **8-Letter Tier**: 3 missing letters | 6-letter bottom deck (3 correct + 3 distractors).
- **🎮 Two Engaging Game Modes**:
  - 🦁 **Word Spelling Quest**: Kid-friendly words (Animals, Food, Nature, Toys, Sky) with vibrant emoji illustration clues!
  - 🔤 **Alphabet Order Sequence**: Master letter sequence chains (e.g. `A B [C] D`, `J [K] L M [N] O`).
- **🔠 ABC / abc Case Toggle**:
  - Switch instantly between **UPPERCASE (Caps)** and **lowercase (small)** letters with one tap.
- **⭐ 3-Attempt Learning Assistance**:
  - 3 golden stars per puzzle.
  - If a child misses 3 times, the game gently illuminates the correct letter so they learn the answer smoothly before moving forward.
- **🎨 Tactile 3D Blocks & Toy Shelf Tray**:
  - Chunky rounded blocks with 3D bevels, pastel colors, and soft bouncy placement animations.
  - Distinct lower toy shelf tray holding the letter deck.
- **🔊 Procedural Web Audio Engine**:
  - Zero external MP3 files! Procedural wooden block clacks, slot snaps, gentle "uh-oh" bounces, and celebratory victory fanfares.
- **💾 Local Score & Streak Tracking**:
  - Puzzles solved, highest streak, and stars earned saved in `localStorage`.

## 🕹️ Controls & How to Play

| Input | Action |
| :--- | :--- |
| **Tap Letter in Deck** | Selects letter from bottom shelf |
| **Tap Empty Slot** | Places selected letter into slot |
| **Tap Placed Letter** | Returns letter back to the deck |
| **ABC / abc Button** | Toggles between uppercase and lowercase |
| **Mode Switcher** | Toggles Word Spelling vs Alphabet Sequence |
| **4 / 6 / 8 Buttons** | Changes quiz length tier |
